개인정보처리방침

SPOO(이하 "본 서비스")는 스포츠강좌이용권 관련 정보를 안내하기 위해 만들어진 비공식 서비스입니다. 정부 또는 지자체가 운영하는 공식 서비스가 아니며, 실제 신청·결제는 대행하지 않습니다.

1. 수집하는 정보

자가진단 과정에서 아이의 나이, 가구 유형, 이전 이용 여부를 입력받습니다. 거주 지역 검색을 위해 위치 정보 접근을 요청할 수 있습니다.

2. 정보의 저장 위치

입력하신 정보는 본 서비스 서버로 전송되지 않으며, 사용 중인 브라우저(기기)의 로컬 저장소(localStorage)에만 저장됩니다. 다른 사용자나 운영자가 이 정보를 열람할 수 없습니다. 브라우저 데이터를 삭제하면 함께 삭제됩니다.

3. 위치 정보

가까운 시설을 찾기 위한 목적으로만 일회성으로 사용되며, 별도로 저장되지 않습니다.

4. 외부 서비스 연동

SPOO는 아래 외부 서비스의 스크립트를 불러옵니다. 이 과정에서 각 사업자의 정책에 따라 최소한의 접속 정보(예: 접속 도메인·브라우저 정보·IP)가 해당 사업자에 전달될 수 있습니다. SPOO가 이용자 정보를 이들에게 별도로 넘기지는 않습니다.

  • 네이버클라우드 지도 API — 지도 표시 및 주소 좌표 변환
  • 카카오 — 결과를 카카오톡으로 공유하는 기능
  • Cloudflare CDN(cdnjs) — 화면을 이미지·PDF로 저장하는 기능에 쓰는 라이브러리
  • SheetJS CDN — 지역 현황을 엑셀 파일로 내려받는 기능에 쓰는 라이브러리
  • jsDelivr — 본문 글꼴(Pretendard) 제공

SPOO는 방문자 수를 세거나 행동을 추적하는 분석 도구를 설치하지 않습니다.
